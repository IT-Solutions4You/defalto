# Users ownership

- `Users` owns user records in `vtiger_users`; `Users_Install_Model` owns field/schema setup, and `Users::$moduleVersion` is the install/update version.
- `Users_Privileges_Model::recalculateSharingRules()` owns rebuilding both privilege and sharing files for every active user. The legacy global `RecalculateSharingRules()` function is a compatibility facade only.
- `Users_Privileges_Model::getPermission()` owns current-user module, action, record ownership, and sharing evaluation. `Users_Privileges_Model::isPermitted()` exposes the boolean API, while the legacy global `isPermitted()` function in `include/utils/UserInfoUtil.php` is a compatibility facade only. An action permission value of `0` must continue into record-level ownership and sharing checks; only a missing action entry may take the module-level early-allow path.
- `Users::retrieve_entity_info()` preserves the encoded values expected by existing runtime callers and registers raw database values in `TrackableObject`. `Users::insertIntoEntityTable()` restores a raw value only when the corresponding field remains unchanged, preventing server-side user saves from persisting or multiplying HTML entities.
- Users remains loadable during module-only or partially applied updates where `TrackableObject::setRetrievedValue()` and `getValueForSave()` are not available yet. In that compatibility state it uses the legacy value assignment and save flow; deploy the matching `data/CRMEntity.php` to enable raw-value preservation.
- Validate an existing user containing encoding-sensitive text with `php tests/integration/EntityHtmlPersistenceTest.php --module=Users --record=<id>`. The test deliberately bypasses user lifecycle side effects and rolls back its direct persistence check.
- User signature editing uses `layouts/d1/modules/Users/resources/Edit.js::registerSignatureEvent()` to attach CKEditor to `signature`, although its install metadata uses uitype 21. `Users/actions/Save.php` and `SaveAjax.php` sanitize signature HTML before persistence; do not replace that sanitization with content-format detection.
- `Users_Field_Model::$htmlFields` contains only `signature`. The inherited `isHtmlField()` exposes its HTML semantics to workflow substitution without changing other user fields or editor behavior. `ITS4YouEmails_Record_Model::getSignature()` separately retrieves the decoded signature for automatic appending.
- The signature editor inherits CKEditor full-page mode. Workflow preserves the complete value of fields marked as HTML, including html/head/body wrappers, styles and explicit breaks; it does not normalize those wrappers.
- Validate field-model inheritance, signature classification, plain-text fallback, and workflow HTML preservation with PHP lint and an isolated manual harness; verify final spacing in a delivered workflow email when a configured runtime is available.
