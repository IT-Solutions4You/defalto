# Profiles

Profiles control which CRM modules, actions, and fields are available to users assigned to a role.

In Settings, open a profile to review its module access. A green enabled control means the profile has stored permission for that module. If permission data is missing, the module is shown as disabled so the screen matches the user's effective access.

After an update that repairs missing module permissions, affected users receive access to the installed modules automatically; administrators do not need to resave every profile.
