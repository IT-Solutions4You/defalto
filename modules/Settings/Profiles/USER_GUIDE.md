# Profiles

Profiles control which CRM modules, actions and fields are available to users through their role. Manage them in Settings, under Profiles.

- Open a profile to review its module access. An enabled module has stored permission in the profile; if the permission data is missing, the module is shown as disabled so the screen matches the users' effective access.
- Saving a profile applies the changes to its users' access immediately.
- When you delete a profile, choose another profile to take over for roles that would otherwise be left without one.
- After an update that repairs missing module permissions, affected users get access to the installed modules automatically; you do not need to resave profiles.
