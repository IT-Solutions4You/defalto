# Settings Vtiger

- Settings navigation is owned by `Settings_Vtiger_Menu_Model` (`vtiger_settings_blocks`) and `Settings_Vtiger_MenuItem_Model` (`vtiger_settings_field`). The sidebar reads persisted items, not `defaultMenuItemLinks` directly. Additions for existing installations require a schema migration through these model APIs; keep the default definition for new installations. `active = 0` means visible.
- Summary Widgets is shared CRM functionality, with no separate installable module version. Its default settings link is `LBL_SUMMARY_WIDGET_EDITOR` in `LBL_MODULE_MANAGER`, targeting `index.php?parent=Settings&module=Vtiger&view=SummaryWidgets`. Labels are supplied by central `languages/<locale>/Settings/Core.php` files.
- The administrator views `SummaryWidgets` and `SummaryWidgetEdit` and action `SummaryWidgetsAjax` delegate widget persistence to `Settings_Vtiger_SummaryWidgets_Model`. Configuration is per source module in `vtiger_links` (`DETAILVIEWWIDGET`); even/odd sequences represent the left/right columns. Registered widgets are disabled with a `block://` URL; custom list widgets are deleted when removed.
- Default widget definitions belong to `Core_Install_Model`; list widget data belongs to `Core_SummaryWidgetList_Model`. Editor assets are under `layouts/d1/modules/Settings/Vtiger/resources` and loaded by their views.
- Validate changed PHP and migrations with `php -l`. For migrations, check repeat execution and preservation of unrelated settings items. Resource JavaScript changes require the existing ScriptsValidator.
