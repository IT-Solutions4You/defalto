# Mail Manager

Mail Manager connects CRM mailboxes, displays messages, and supports relating email and attachments to CRM records. Reply, Reply all and Forward open the Emails composer, so replies and forwards are sent the same way as other CRM email.

Newly saved attachments use the configured attachment storage directory, including an absolute directory outside the public web directory.

When adding a comment from Mail Manager, you must have permission to create comments and to view the selected related CRM record.
