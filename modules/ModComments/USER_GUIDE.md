# Comments

Comments can include file attachments. Attached files can be previewed or downloaded according to CRM permissions and remain available when attachment storage is configured outside the public web directory.

Users can add comments only when their profile allows creating comments and they can open the related CRM record. The same rule applies to individual, bulk, and Mail Manager comments.

Public comments can be reused in customer-facing content. Internal comments remain visible only to CRM users and are not included when a ticket is converted into a knowledge base article.
