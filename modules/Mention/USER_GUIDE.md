# Mention

Mention lets you address colleagues and groups in record comments.

Suggestions match the CRM theme, showing each person's avatar or a group icon, their display name and their mention name. Use the arrow keys and Enter, or click a suggestion, to select a recipient. Long names are shortened to keep the menu readable.

Open a record with comments, type `@`, and choose a person or group from the suggestions. You can also use mentions when adding comments from a list. Save the comment to notify the selected recipients by email. Group mentions notify the group's users, with each user included once.

Suggestions follow your accessible users and groups and can include the record's active owners. Your administrator can customize suggestions for each module, so list and record suggestions may differ when a rule requires a saved record.

Email notifications require the Emails module and a configured outgoing mail server. Notifications include the comment and a link to the related record. Record access still follows CRM permissions.

Administrators manage the extension through Module Manager and Installer. Disabling Mention removes its suggestions and automatic mention notifications without deleting existing comments.
