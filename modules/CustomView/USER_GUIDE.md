# Saved lists

Create or edit a saved list to choose columns, conditions, sorting and sharing. The condition options match the quick filter for the same field. Text and selection fields support their applicable comparisons; checkbox conditions select Yes or No.

For dates, choose a fixed day/range or a moving period such as Today, Last month or Last X periods. Relative day/hour comparisons take a number. Time ranges take two times. Save the list and reopen it to review its criteria.

Module-specific condition options apply to both saved lists and quick filters. Both paths use the same preparation of condition values before filtering records.

Save as filter in the quick-filter dropdown opens a new draft containing the selected list's criteria plus the additional conditions. Review the condition groups, give the new list a name, and save it. Clearing temporary conditions does not erase the saved list's criteria.
