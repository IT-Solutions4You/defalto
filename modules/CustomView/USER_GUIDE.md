# Saved lists

Create or edit a saved list to choose its columns, conditions, sorting and sharing. There is no maximum number of columns; pick the fields you need and arrange their order. Use Cancel or Save in the editor's footer when you are done.

## Conditions

- A new list without conditions starts with one empty condition row. Choose a field in it; there is no need to click Add condition for the first rule.
- Choose AND or OR beside a condition to connect it to the next one. The last row in each group has no connector. Each choice is kept when you save and reopen the list or create a draft with Save as filter.
- The available comparisons match the quick filter for the same field, including any module-specific options. Checkbox conditions select Yes or No.
- For dates, choose a fixed day or range, or a moving period such as Today, Last month or Last X periods. Relative day/hour comparisons take a number, and time ranges take two times.

## Save as filter

Save as filter in the quick-filter dropdown opens a new draft with the selected list's criteria plus your additional conditions. Review the condition groups, give the new list a name and save it. The original list is not changed, and clearing temporary conditions does not erase a saved list's criteria.
