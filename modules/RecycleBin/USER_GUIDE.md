# Recycle Bin

Users with access to the Recycle Bin can review deleted records by source module. Only administrators can restore records, permanently delete selected records or empty the whole Recycle Bin.

Filters narrow the list using ordinary field conditions. OR groups remain restricted to deleted records; the count and mass actions follow the same filters. If all results are selected and individual rows are then cleared, those rows remain excluded from the action.

Permanently deleting a record removes attachment files from the configured persistent storage directory only when no other record, user image or stored email still uses them.
