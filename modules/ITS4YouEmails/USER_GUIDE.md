# Emails

The Emails module composes and sends CRM email, supports templates, related records, file attachments, and embedded images. Attachments can be selected from Documents or added by supported mail workflows.

When composing an email, use the attachment menu to select a file from all CRM Documents or from Documents related to the current record. The document picker opens above the composer; select the required documents and confirm the selection to attach them without leaving the email.

Physical attachment storage may be configured outside the public web directory. Email sending resolves both older relative paths and newer absolute paths automatically. Administrators must include the configured attachment directory in backups.
