# Two-factor authentication

Two-factor authentication protects CRM sign-in with an additional code after the password. Depending on the administrator's configuration, the code can be delivered by email or generated by an authenticator application. Backup codes can be used when the normal second factor is unavailable.

If you already have an authentication method, the sign-in screen always asks for that method. For security, you cannot change to another method until you successfully sign in with your current factor.

If this is your first protected sign-in and no method has been selected for your account, choose one of the available methods and complete its verification. When the selected method is an authenticator application, scan the QR code and confirm setup with the generated code.

After signing in, open **My 2FA** in My Preferences to change the authentication method, set up or reconfigure an authenticator application, and generate backup codes. Store newly generated backup codes safely because each code works once and the codes are shown only when generated.

If your configured method is no longer available or you have lost access to it and to your backup codes, contact an administrator to reset your 2FA configuration.
