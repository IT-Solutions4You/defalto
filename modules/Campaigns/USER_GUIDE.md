# Campaigns user guide

Campaigns help you organize marketing activities and manage their target members. A campaign can contain Accounts, Contacts, and Leads, which are available from the related lists on the campaign detail page.

## Adding campaign members

Users who can edit the campaign can add individual members or add all matching records from a saved filter. Records already related to the campaign are not duplicated.

New members start without a contact outcome. This keeps planned campaign audiences separate from members who have actually been contacted.

## Updating member status

Use the status control in the campaign's related list to record the outcome after contact. Available outcomes include successful contact, unsuccessful contact, and never contact again.

If the selected member or status is invalid, the status is not changed and the application asks for a valid status selection.

## Practical tips

- Build and review a saved filter before using it to add many members.
- Confirm the campaign audience before sending messages or starting follow-up work.
- Set a member status only after the corresponding contact attempt has taken place.
